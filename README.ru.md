# Friday 2.0

Открытый голосовой ассистент для Windows на Python, разработка через тесты.

**Статус:** ранняя разработка (этапы 0-11 готовы). Уже работает как голосовой
чат, который умеет управлять Яндекс Музыкой: зажми боковую кнопку мыши X2,
говори, слушай ответ. Законченным продуктом пока не является.

## Что уже есть

- Push-to-talk на боковой кнопке мыши X2
- Распознавание речи на видеокарте (faster-whisper)
- Облачная нейросеть с цепочкой запасных бесплатных провайдеров
- Голосовые ответы (Edge TTS)
- Короткая память диалога
- Окно (PyWebView) с перепиской и индикатором состояния
- Управление Яндекс Музыкой голосом (пауза, продолжить, дальше, назад, что играет)
- Включение песни или целого исполнителя в Яндекс Музыке по названию (нужен `YM_TOKEN` в `.env`)
- Запуск «Моей волны» в Яндекс Музыке голосом: «включи мою волну» (работает при закрытом или свёрнутом приложении; если оно открыто на другой странице, сначала открой «Мою волну»)
- Долговременная память голосом: «запомни, что ...», «что ты обо мне помнишь», «забудь про ...»
- Описание экрана голосом: «что на экране» (снимок уходит облачной нейросети)
- Слово-активатор (по желанию): говори «Пятница, ...» вместо зажатия X2 (`WAKE_WORD=1` в `.env`, по умолчанию выключено)

## Приватность

Сохранённые факты лежат только на твоём компьютере в `data/memory/facts.json` (в git не
попадают). Но при каждом ответе они уходят облачным нейросетям в составе запроса, поэтому
не диктуй ассистенту то, что не хочешь им показывать.
Когда ты спрашиваешь, что на экране, делается снимок всего экрана, уменьшается и отправляется
облачной нейросети (Cloudflare Workers AI, запасной вариант OpenRouter). Он хранится только в
памяти и на диск не сохраняется, но перед вопросом закрой всё личное.
Если включить слово-активатор, микрофон слушается постоянно, и всё, что говорится рядом, распознаётся
на твоём компьютере локальной моделью Whisper. Звук никогда не сохраняется, а распознанный текст не
пишется в лог, кроме режима `WAKE_DEBUG=1` (он выводит услышанное в консоль, только для настройки).
Фразы без имени отбрасываются на твоём компьютере; текст фразы, которая начинается с имени, уходит
облачным нейросетям, как любая другая команда.

## Запуск

Создать окружение `py -3.11 -m venv .venv`, активировать
`.venv\Scripts\Activate.ps1`, затем `pip install -r requirements-local.txt`.

Скопировать `.env.example` в `.env` и заполнить, затем:

    python -m friday.voice

Зажми боковую кнопку мыши X2 и говори. Закрой окно, чтобы выйти.
Для распознавания речи нужна видеокарта NVIDIA (проверено на RTX 5050).

Запуск тестов: `pytest`.
